The CMIG BIDS app is shared as a container image holding multiple components:
  A. The compiled CMIG BIDS app and its container image
  B. Scripts and configuration files
  C. Miscellaneous libraries
  D. Brain atlas image files
  E. Gradient nonlinearity field correction files
  F. Publicly available and/or redistributable software
    a. AFNI
    b. ANTs
    c. Convert3D (c3d_affine_tool)
    d. FreeSurfer
    e. FSL
    f. GNU Scientific Library
    g. Intel C++ Compiler and Math Kernel Library runtime libraries
    h. libg2c (GNU Fortran 77 runtime library)
    i. MATLAB Runtime
    j. MNI ICBM152 2009c atlases (with Synb0-DISCO)
    k. Python and Python packages
    l. Rocky Linux
    m. Synb0-DISCO
    n. TORTOISE

Paths below are inside the image. The license texts named are in
/documentation/licenses; those of the third-party packages are copied there
from each package as installed when the image is built.
